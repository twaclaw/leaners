# Introduction

> This is a collection of notes, references and shared experiences about software verification with [Lean](https://lean-lang.org/). It is also self-referencing: the site renders its own pages with a Markdown renderer written in Rust, whose escaping, URL and slug functions are mechanically extracted to Lean by [charon](https://github.com/AeneasVerif/charon) and [Aeneas](https://github.com/AeneasVerif/aeneas), and proved correct there. See [About this Site](./about-this-site.md) for details.


Over the past few months, I have discussed the following three topics with you at length:

1. Software and hardware verification and theorem proving using [Lean](https://lean-lang.org/).
2. Using AI to optimize or improve code and algorithms. For example, _searching_ for new candidates using strategies like those delineated by [AlphaEvolve](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/) and [OpenEvolve](https://github.com/algorithmicsuperintelligence/openevolve). This is one of the reasons why I bought my new, noisy laptop.
3. Using AI to create faster or more accurate physical simulations.


These three topics are related. For example, having provably correct software provides solid verification for AI-driven algorithm optimization.

The purpose of this site is to compile a list of tips, links, and experiences.

Please edit the existing pages or [add new ones](./adding-a-page.md) if needed.
